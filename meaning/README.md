# meaning/ — Marley1 message type: MTP v0.1 "meaning packet"

This is **MTP (Mesh Transport Protocol) v0.1's first IMPLEMENTED message type**, and the
node's **first trust primitive**: an ed25519 *node identity* used to sign every packet and
verify every received packet before it is rendered.

**Decoupled by design.** This module does **not** import, wrap, or modify `marley_server.py`.
It is a standalone message type the rest of the mesh can adopt independently.

## Node identity (trust primitive)

- ed25519 keypair, **reused from the original demo — never regenerated by this module**:
  - private seed : `~/.meaninglayer/key`        (hex 32-byte seed; never committed)
  - pinned peers : `~/.meaninglayer/peers.json`  (`{fingerprint: pubkey_hex}`)
- `from` = first 16 hex chars of `sha256(pubkey)` — the node fingerprint.
- Every packet is signed over the canonical `{intent, pri, sem}` payload and verified
  against the sender's pinned pubkey **before** rendering. Unknown sender or bad signature → `400`.

Fat Man's identity fingerprint: `cc5315d880d69787` (pinned on Little Boy).

## Packet schema (MTP v0.1)

```json
{
  "mp": "0.1",
  "id": "<uuid4>",
  "from": "<ed25519 fingerprint>",
  "sig": "<hex ed25519 signature over canonical {intent,pri,sem}>",
  "ts": "<iso8601 utc>",
  "intent": "alert|question|instruction|observation|discussion",
  "pri": "emergency|info|routine",
  "src_lang": "en",
  "sem": { "summary": "...", "entities": ["..."], "actions": ["..."] }
}
```

## API — `packet.py`

- `encode(text, src_lang="en") -> dict` — local-LLM semantic extraction → unsigned packet
- `sign(packet) -> dict` — attach ed25519 signature using the node identity
- `verify(packet, peer_pubkey) -> bool` — check signature against pinned peer pubkey
- `render(packet, target_lang="es") -> str` — one short paragraph, **priority-prefixed**

Priority prefixes (unchanged): `emergency → [ALERTA]`, `info → [INFO]`, `routine → [RUTINA]`.

## Runner — `node.py`

- `python3 node.py send "english text"` — sender: encode + sign + POST to peer
- `python3 node.py serve` — receiver: Flask `:8082` verify + render endpoint

The receiver runs under **systemd** (`meaning-render`), with `MEANING_LLAMA_URL` pointed at
the local `:8081` llama-server. Config via env: `MEANING_LLAMA_URL` (default `:8080`),
`MEANING_PEER_URL`, `MEANING_KEY`, `MEANING_PEERS`, `MEANING_INBOX`.

## Summary-compression hook (seam only)

`encode()` routes `sem.summary` through `~/marley1/compression/abbrev.py`
(`ConstructionCompressor.compress`) when `USE_ABBREV = True` in `packet.py`.

It is **OFF by default** (`USE_ABBREV = False`) — the LLM summary is used. This commit wires
only the seam; no optimization is enabled. On any import/runtime failure it falls back to the
LLM summary.

## Provenance

Promoted from the standalone demo (`mp_encode.py` / `mp_render.py`, kept alongside as `*.bak`).
Reuses the same keys and pinned peers — **no re-pinning, no new identities**.
